# CS:SO Launcher (Beta)

This is a **beta** launcher for *Counter-Strike: Source Offensive* (CS:SO).

🔧 **Current Features**:
- Launch the game with custom player name and parameters.
- Modern interface with language selection.

⚠️ **Limitations**:
- Currently does **not save settings automatically** (name, language, or parameters).
- Requires **Electron compilation** to run.

📦 **Basic Usage**:
1. Install dependencies using `npm install`.
2. Run the launcher with `npm start` or package it using `electron-packager` or `electron-builder`.
